# GDinamy

Gestión de copias de seguridad completas y parciales de bases de datos MongoDB, mediante una app de escritorio (Tauri + Vue 3 + Vuetify + Pinia) que embebe los binarios oficiales de MongoDB Database Tools (`mongodump`, `mongorestore`, `mongoexport`, `mongoimport`).

## Desarrollo

```bash
npm install
npm run tauri dev
```

## Build

```bash
npm run tauri build
```
